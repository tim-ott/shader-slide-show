## Shader Playground

Interactive GLSL transition explorer built with React, Vite, and `three.js`.  
The app lets you browse a set of shader-based transition effects, tweak their uniforms live, and copy/export the resulting configuration.

## Getting started

```bash
pnpm install   # or npm install / bun install
pnpm dev       # or npm run dev / bun dev
```

Then open `http://localhost:8080` in your browser.

## Tech stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui
- three.js + @react-three/fiber

## Scripts

- `dev` – run the local development server
- `build` – production build
- `preview` – preview the built app
- `lint` – run eslint
- `test` / `test:watch` – run unit tests with Vitest
